# MiniMax-AI
> This project is a fork of [KeithGalli/Connect4-Python](github.com/KeithGalli/Connect4-Python) with other algorithms added.

In this project, my teammate and I implemented the Genetic Algorithm, Minimax, Monte Carlo Tree Search (MCTS), and Deep Q-Network (DQN) algorithms to play Connect-4. The game can be played in either Human vs AI mode or AI vs AI mode.

## Usage

To start the game, run the 'main.py' script:
```sh
python src/main.py
```
